# Pendientes antes de circular el consentimiento informado

Lista de verificación extraída de `01_consentimiento_informado_v1.0.md` y `v1.1.md` (notas internas
retiradas de ambos documentos el 22 sep 2026, para no circularlas con el consentimiento).

- [ ] Confirmar con el comité de ética o la oficina de protección de datos de la universidad si el
      estudio requiere aval formal.
- [ ] Confirmar si la universidad tiene un formato institucional obligatorio de consentimiento
      informado; si lo tiene, adaptar `01_consentimiento_informado_v1.1.md` a ese formato (este
      documento es una base, no sustituye ese trámite).
- [ ] No enviar el consentimiento a los participantes hasta resolver los dos puntos anteriores.
